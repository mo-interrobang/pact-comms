# ZBA Appeal Conflict — Citations & Evidence

A single self-contained HTML page (`index.html`) documenting the sourced factual record behind a letter sent to Allen Park, Michigan city council on September 9, 2026, regarding a dual-role conflict of interest in the handling of a zoning board of appeals (ZBA) matter.

Every claim on the page is backed by a cited source: FOIA-produced emails, a court-stamped filing from a separate township's litigation, an ordinance draft, and a public meeting recording. Two of the source emails are reproduced as embedded scanned images directly in the page.

## Viewing it

Open `index.html` in any browser, or enable GitHub Pages for this repository (Settings → Pages → deploy from the `main` branch) to get a hosted link.
